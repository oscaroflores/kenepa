# Cuestionario de estilo visual para Kenepa

Responde estas 10 preguntas con ejemplos, referencias o preferencias concretas cuando puedas. La meta es definir una dirección visual clara antes de diseñar la interfaz.

1. **Personalidad del producto:** ¿Kenepa debe sentirse más como una herramienta financiera seria y sobria, una app moderna de análisis accionable, o una experiencia más editorial y explicativa? El sentimiento, como tal, de Kenepa debería ser juguetón, debería ser pictoresco, debería ser cartoonish. 

2. **Audiencia principal:** ¿Quién usará la interfaz primero: inversionistas individuales, analistas financieros, fundadores/equipos internos, o usuarios no técnicos que necesitan interpretación guiada? Inversionistas individuales y retail 

3. **Densidad de información:** ¿Prefieres una interfaz densa tipo terminal/dashboard profesional con muchas métricas visibles, o una interfaz más espaciosa que priorice pocas señales importantes por pantalla? Interfaz espaciosa, moderna, minimalista y cartoonish. 

4. **Paleta visual:** ¿Qué familias de color te atraen o quieres evitar para Kenepa? Por ejemplo: verdes financieros, negro/blanco editorial, tonos tropicales sutiles, azul corporativo, alto contraste, etc. todo blanco + negro para bordes y texto y eso. usar foto de logo para decorar la pagina. a componentes en pagina añada accents del color:  #f49603

5. **Tono de marca:** ¿La marca Kenepa debe comunicar confianza institucional, claridad pedagógica, inteligencia crítica, energía caribeña, minimalismo premium, u otra cualidad?

6. **Jerarquía de datos:** Cuando el usuario abre la app, ¿qué debe dominar visualmente: puntaje general, señales de riesgo, valuación, eventos recientes, comparación histórica, fuentes, o recomendaciones?

7. **Navegación:** ¿Te imaginas Kenepa como una app con sidebar fija, navegación superior compacta, pestañas por secciones, o un flujo más guiado tipo reporte? sidebar fija definitivo

8. **Tratamiento de gráficos:** ¿Los charts deben ser sobrios y técnicos, visualmente ricos y explicativos, o una mezcla donde los datos críticos tienen anotaciones y contexto? 

9. **Referencias externas:** ¿Hay productos, dashboards, sitios o apps cuyo estilo te guste para Kenepa? Incluye también referencias negativas: interfaces que no quieres que se parezca. notion pero con el twist de nuestro logo de kenepa y el color #f49603 utilizado conservadoramente.

10. **Nivel de distintividad:** ¿Quieres que Kenepa se vea claramente único y memorable, o que se mantenga familiar y conservador para reducir fricción en usuarios financieros? memorable!
